This update includes a critical TLS security fix that blocks compromised eMudhra certificates. 

In October 2026, eight eMudhra intermediate CA certificates were [reported as compromised](https://emudhra.we-have-a-problem.com/), potentially allowing attackers to forge trusted HTTPS certificates. Although browsers and operating systems have [blocked these certificates](https://blog.google/security/protecting-chrome-and-android-users-from-compromised-emudhra-intermediate-ca-certificates/), Dart applications on Android, Windows, and some Linux environments require a separate fix because they use their [own TLS](https://groups.google.com/g/flutter-announce/c/0hNyXI3SSRk) certificate validation system.
